Talk2View for LibreOffice Writer

An AI-powered document assistant for LibreOffice Writer. Opens a Talk2View
chat panel beside your document and lets you ask the assistant to read, edit,
format, restructure, and review your document using natural language.

Key Features:
- Docked chat panel, available alongside your document
- 21 document tools covering reading, writing, formatting, search,
  structure, and commenting
- 13 high-level skills for document creation, restructuring, reviewing,
  and template filling
- Powered by the Talk2View cloud engine

Requirements:
- LibreOffice 7.0 or later
- Talk2View account (partner key + user login)
- Internet connection (cloud backend)

For more information, visit https://talk2view.com
